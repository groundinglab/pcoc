# Conformance vectors

The **one pack** is [pack/](pack/). `pack/manifest.json` lists the files present. `sdk/SPEC_PIN` names tag `spec-2.3.0` and the SHA-256 of that manifest.

How the pack is used (producer / verifier claims, permanent negatives, precedence) is defined in [../05-Conformance_Process.md](../05-Conformance_Process.md). Start with [../GUIDE.md](../GUIDE.md) for which documents you need.

This directory holds the pinned vectors only. Interop kits and monolith trees are not part of this branch’s public `spec/` face.
