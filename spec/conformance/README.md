# Conformance vectors

The **one pack** is [pack/](pack/). `pack/manifest.json` lists the files present. Its id `pack-2.2.0` is a historical name; the bytes are valid for Satoshi Hike **2.3** (tag `spec-2.3.0`). `sdk/SPEC_PIN` names that tag and the SHA-256 of the manifest.

How the pack is used (producer / verifier claims, permanent negatives, precedence) is defined in [../05-Conformance_Process.md](../05-Conformance_Process.md). Start with [../GUIDE.md](../GUIDE.md) for which documents you need.

This directory holds the pinned vectors only.
