## Rights decision and counts

No original workflow-source body, full operational playbook, policy file, historical template or harness is redistributed: the selected source distribution has no established transferable license/provenance sufficient for that copy. Source-owner/third-party clearance remains open. The destination license does not resolve source rights, so **zero of ten raw recipes are included**.

Instead this release contains seven newly written portable method descriptions in [skills](../skills/README.md), plus one explicitly proposed stamping-method description. These are original task-driven guidance, not alleged licensed copies or installed replacements. Two lab-gate sources share one method description; onboarding and produce-ladder research have no substantive public replacement. Reconciliation: 10/10 accounted for; 8 sources mapped to 7 portable references, 2 deliberately omitted; all 10 original bodies omitted. The stamp paragraph is additional and unvalidated. No claim “all internal skills published.”

All new prose files are per-folder READMEs within the existing [documentation-license scope](../../LICENSE-DOCS.md); no scope extension or third-party relicense is made. Existing code/notice licenses remain unchanged. The website's existing renderer/vendor notices are preserved. The kit contains no copied executable harness or new automatic validator.
