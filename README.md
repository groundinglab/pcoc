# pcoc

A PCOC is a small object anyone can check. The intended produce cost does not divide across bulk copies. Copying the file is cheap. A new public key means a new hike.

## Why collateral

Bind the cost into the object, and anyone who holds the object can check it. A relying party can require one as collateral for admission or as the Sybil cost of one more identifier. Verify answers whether the object matches the construction. Attaching a pass to any of those uses is the relying party's choice.

## First principles

The Bitcoin tip is the shared public sequencer. Successive tips pace the stages and order them. That is the whole of its role: not a payment, not a confirmation count, and not an archive of the chain. The hike is the quantity of work.

Produce reads the tip and opens a stage. Legs run while that tip holds. A later tip closes the stage. Satoshi Hike v2.0 records eighteen stages. A leg is two million steps on terrain fixed by the public key and the seed beacon, and it ends in a leg result. Checking the checkpoint bind does not repeat the leg.

The object does not store the terrain. Anyone can recompute it from the claimed public key and the seed beacon. See [Satoshi Hike v2.0](spec/satoshi-hike-v2.0/Satoshi-Hike-v2.0.md).
