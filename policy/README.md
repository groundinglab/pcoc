# Policy

A policy sets the SPEC §15.4 levers to values inside their ranges. It never changes a SPEC rule.

The active groundinglab policy is [groundinglab-admission/gl-admit-v9.toml](groundinglab-admission/gl-admit-v9.toml).

`born_height` in that file is policy, not a SPEC lever. See [POLICY.md](groundinglab-admission/POLICY.md).
